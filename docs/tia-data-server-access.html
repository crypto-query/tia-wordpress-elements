3. Key finding: Hostinger sends over IPv6 first

The site's inbound IP is not its outbound IP. The DNS address of tiainvestor.com is 145.14.147.195. But PHP on Hostinger connects over IPv6 first, from 2a02:4780:1:1055:0:1fbf:82a2:1. IPv4 is only the fallback. Always allowlist both addresses.

7. PHP example

This example sends the same body as the tested call. Put the base URL in the plugin settings, not in code.

<?php
function tia_fetch_forecast_curves( $base_url ) {
    $response = wp_remote_post( $base_url . '/forecast_curves_data', array(
        'timeout' => 10,
        'headers' => array(
            'Content-Type' => 'application/json',
            'Accept'       => 'application/json',
        ),
        // Always send "curves": the server returns 500 without it.
        'body'    => wp_json_encode( array(
            'id'        => 'dji',
            'base_year' => 2026,
            'curves'    => array( array( 'id' => 0 ) ),
        ) ),
    ) );

    if ( is_wp_error( $response ) ) {
        // Network error, DNS error or timeout.
        error_log( 'TIA data server: ' . $response->get_error_message() );
        return false;
    }

    $code = wp_remote_retrieve_response_code( $response );
    if ( 403 === $code ) {
        // The egress IP of this server is not on the allowlist. See section 9.
        error_log( 'TIA data server: 403, egress IP not allowlisted' );
        return false;
    }
    if ( 200 !== $code ) {
        error_log( 'TIA data server: HTTP ' . $code );
        return false;
    }

    // { ids: int[], columns: string[], index: int[] (epoch ms), data: (float|null)[][] }
    return json_decode( wp_remote_retrieve_body( $response ), true );
}

$data = tia_fetch_forecast_curves( 'https://tia-data-server.cryptoquery.eu' );

9. Troubleshooting

SymptomCauseFix
403 from the WordPress server The egress IP is not on the allowlist. Hostinger can change the site's IPv6 address. Find the blocked IP in the nginx log (needs Dokku SSH access): 
ssh dokku@contabo nginx:access-logs tia-data-server-prod | awk '$9==403{print $1}' | sort | uniq -c
Add that IP to the allowlist (section 10).
403 in the browser The call runs in visitor JavaScript, not in PHP. Move the call to PHP (section 5).
403 on a dev machine The dev IP is not on the allowlist. Use a local dev data server, or add the IP.
525 or other SSL error from Cloudflare Cloudflare cannot complete TLS to the origin. Set Cloudflare SSL/TLS mode to Full (strict). Check that the origin Let's Encrypt cert is valid.
404 on / The app has no root route. None. This is normal. Call a real route.
500 'NoneType' object is not iterable POST /forecast_curves_data without curves. Always send curves (section 6).

10. Change the allowlist

NeedsValue
Accessssh mitja@contabo with sudo

DowntimeNone. A reload keeps open connections.
  1. Connect to contabo: 
    ssh -t mitja@contabo
  2. Edit the file with sudo. Add or remove the address in the same form as the existing entries: 
    sudo nano /home/dokku/tia-data-server-prod/nginx.conf.d/allowlist.conf
  3. Test the nginx config. Do not continue if it fails: 
    sudo nginx -t
  4. Apply the change: 
    sudo systemctl reload nginx
  5. Run the check in section 8, step 3. Expect 200.

11. Known risks (accepted)

RiskEffectMitigation
Shared hosting IP Other Hostinger sites that share 145.14.147.195 also pass the allowlist. Add an API key later.
IPv6 can change If Hostinger changes the site's IPv6 address, the plugin gets 403. Log 403 in the plugin. Follow section 9.
Cloudflare ranges are hard-coded The file lists 22 Cloudflare ranges. If Cloudflare adds ranges, nginx does not trust CF-Connecting-IP from them. Calls through those ranges get 403. Update the ranges in the file by hand.
No API key Any allowed IP can read all data. The plugin's Access Cut-off hides data only in the plugin's own output. Consider an API key header later. The plugin then needs a settings field for it.
Docker bridge is open Every container on contabo's default Docker network (172.17.0.0/16) can call the data server. None needed. All of them run on the same server.
